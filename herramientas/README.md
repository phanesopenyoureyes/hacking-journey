# Herramientas

Cada herramienta es una carpeta con su `README.md` (y `capturas/` si hace falta).
Para crear una:

```bash
scripts/nueva-herramienta.sh "Nombre de la herramienta"
```

Rellena el front-matter y las secciones, pon `estado: publicado` y haz `git push`.
Aparecerá sola en la sección **Herramientas** del sitio.
